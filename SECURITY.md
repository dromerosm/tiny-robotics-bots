# Security policy

## Supported versions

Only the latest commit on `main` and the latest release are supported.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately with GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) ("Report a vulnerability" in the *Security* tab). Include what you found, how to reproduce it and the possible impact.

You can expect a first reply within 7 days.

## Scope

These are learning examples, not production firmware. Still, reports about the build scripts, CI workflows, or code that could harm a device or its user (for example, unsafe servo or motor commands) are welcome.
